Aplicación Web To-Do
Descripción

Aplicación web para gestionar tareas (To-Do) desarrollada usando Arquitectura Hexagonal, Clean Code y principios SOLID.
Permite agregar, actualizar, eliminar y listar tareas en un entorno web interactivo.

Tecnologías

Backend: Python + Flask

Frontend: React

Base de datos: (menciona si usaste alguna, por ejemplo SQLite, PostgreSQL o MongoDB)

Gestión de versiones: Git/GitHub

Funcionalidades

Crear tareas.

Listar tareas.

Editar tareas existentes.

Eliminar tareas.

Instalación y Ejecución

Clonar el repositorio:
git clone https://github.com/ballesteroguido-max/todo-app.git

Entrar en la carpeta del backend y activar el entorno virtual:
cd todo-app-backend
venv\Scripts\activate   # Windows
pip install -r requirements.txt
python app.py

Entrar en la carpeta del frontend y ejecutar:
cd todo-app-frontend
npm install
npm start
